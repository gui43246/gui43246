
Olá! Sou estudante de **Engenharia de Software**, com foco em desenvolvimento backend e construção de APIs.

- Desenvolvimento backend e APIs REST.
- Integração com bancos de dados relacionais.
- Autenticação e segurança de aplicações.

- Aprendizado contínuo de novas tecnologias.
